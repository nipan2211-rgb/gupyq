About the Project

Student Academic Resource Archive is an independent educational project developed to help students access academic resources related to Gauhati University in a simple and organized way. The platform includes previous year question papers, syllabi, entrance examination resources, study materials, and other useful academic documents.

Why This Project Was Built

This project was built because many students face difficulty in finding previous year question papers, admission information, syllabi, and other academic materials. These resources are often scattered across different sources, making them difficult to search and retrieve. The archive aims to bring these materials together in one accessible platform.

Student-Created Initiative

This website is a student-created independent initiative. It has been developed for academic support and student convenience. It is not an official website of Gauhati University and is not affiliated with, endorsed by, or maintained by the University.

Educational Purpose

The main purpose of this archive is educational. It supports students in preparing for semester examinations, entrance examinations, and other academic activities. The project also promotes digital preservation, easy access, and responsible sharing of academic resources.

Non-Commercial Purpose

This project is completely non-commercial. No subscription fee is charged for accessing the resources. The website has been created only to support learning, academic preparation, and educational accessibility.
